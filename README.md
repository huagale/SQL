# Пять учебных SQL-проектов

Проекты показывают фильтрацию, группировки, CASE, подсчёт средних и простые JOIN. В каждой папке один основной analysis.sql, данные, готовая база, README с выводами и свой PNG-дашборд.

| Проект | Тема |
| --- | --- |
| [Отток клиентов интернет-магазина](ecommerce-customer-churn-sql/) | Сравнение клиентов с меткой ухода и без неё |
| [Продажи из CRM и ERP](sql-data-warehouse/) | Соединение таблиц CRM/ERP и анализ продаж |
| [Продажи велосипедов и аксессуаров](retail-sales-analysis-sql/) | Фильтры, выручка, прибыль и товарные категории |
| [Активность клиентов и банковские операции](bank-customer-segmentation-sql/) | Счета, проведённые операции и регионы |
| [Анализ учебного набора госпитализаций](healthcare-analytics-sql/) | Группировки синтетических госпитализаций |

В каждом из папок есть README, в нём указаны источник задания, фактически использованный датасет и основные результаты. В примере продаж закрытый входной файл заменён публичным совместимым набором; файл с данными банка адаптирован к готовым синтетическим данным.
